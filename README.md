
# Vrinda Store Sales Analysis | Excel Dashboard

## Project Overview

This project focuses on analyzing Vrinda Store's sales data using Microsoft Excel to understand sales performance, customer demographics, order status, and purchasing trends.

The project includes data analysis using Pivot Tables, Pivot Charts, and an interactive Excel dashboard to present business insights in a clear and visual format.

## 🎯 Project Objectives

- Analyze sales and order performance.
- Understand customer purchasing patterns.
- Compare sales across different customer demographics and sales channels.
- Identify trends that can support business decision-making.
- Present key metrics through an interactive Excel dashboard.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Organization and Formatting
- Pivot Tables and Pivot Charts
- Data Analysis and Visualization
- Interactive Dashboard and Slicers
- Business Insights

## 📊 Dashboard Features

- Sales and order performance overview
- Customer gender and age-group analysis
- Order status analysis
- Sales channel comparison
- State-wise sales analysis
- Interactive filtering for exploring the data

## 📁 Project File

**`Vrinda Store Data Analysis.xlsx`**

The Excel workbook contains the dataset, Pivot Tables, and dashboard in one file.

## 🔍 Key Learnings

- Organizing and analyzing sales data in Excel.
- Summarizing data using Pivot Tables.
- Creating charts to communicate business trends.
- Designing an interactive dashboard for data-driven decision-making.
